# 专利技术交底书草案

## 一、建议名称

一种基于标定成像模型与配准置信度约束的像素位移超分辨率成像方法、系统、设备及存储介质

## 二、技术领域

本方案涉及计算成像、机器视觉和图像超分辨率领域，尤其涉及由微位移机构、多帧图像采集、亚像素配准、物理成像模型标定和鲁棒反演组成的高分辨率成像方法。

## 三、要解决的技术问题

现有多帧像素位移方案通常直接采用平台指令位移，或使用固定退化核进行插值和迭代。真实系统中存在平台回差、振动、曝光异常、光学散焦、像素积分和信号相关噪声，导致名义位移与实际位移不一致，异常帧参与重建，并使重建结果不能再次生成原始观测。

本方案拟解决：

1. 实际亚像素位移未知或偏离指令值时的配准问题；
2. 异常帧和局部异常像素对多帧反演的破坏问题；
3. 重建退化模型与真实光学、采样和噪声不一致的问题；
4. 无高分辨率真值时缺少客观质量依据的问题；
5. 实验结果无法追溯到输入、参数和软件版本的问题。

## 四、核心技术方案

系统至少包括：

- 图像采集模块；
- 二维微位移执行模块及可选位置反馈模块；
- 标定模块；
- 亚像素配准与置信度计算模块；
- 异常帧判定模块；
- 物理模型一致的超分辨率重建模块；
- 质量评价和结果追溯模块；
- 可选的缺陷检测或尺寸测量模块。

第 k 个低分辨率观测满足：

    y_k = D(B(T(s_k)x)) + n_k

其中 x 为待恢复高分辨率图像，s_k 为实际前向位移，T 为位移算子，B 为标定点扩散函数，D 为像素积分和采样算子，n_k 满足：

    Var(n_k) = a * signal + b

重建目标为：

    min_x sum_k w_k * Huber(y_k - D(B(T(s_k)x))) + lambda * R(x)

其中 w_k 根据配准相关性、有效重叠区域和位移范围确定。低置信度帧被剔除或赋予零/较低权重。

## 五、方法步骤

S1. 锁定曝光、增益、焦距和照明，控制微位移机构按照预定轨迹采集多帧图像，并记录指令位移和可选编码器位移。

S2. 对图像执行位深归一化、尺寸和通道一致性校验，计算文件哈希并关联采集元数据。

S3. 以参考帧为基准，采用相位相关获得整数或粗亚像素对齐位移。

S4. 以粗配准结果初始化增强相关系数优化，得到精细亚像素位移；将对齐位移取反得到物理前向位移。

S5. 根据对齐后的归一化相关系数、有效重叠比例和位移范围计算帧置信度，剔除或降权异常帧。

S6. 使用已知高分辨率标定靶搜索光学 PSF 参数，并根据观测残差拟合泊松-高斯噪声参数。

S7. 使用与前向模型顺序相反的近似伴随算子，将 Huber 截断后的低分辨率残差反投影至高分辨率网格；按伴随覆盖度归一化后更新图像。

S8. 根据相对损失改进量和连续稳定次数停止迭代，并保留损失最小的中间结果。

S9. 将重建结果再次通过同一前向模型投影，计算逐帧重投影误差；输出图像、置信度、收敛过程、质量指标和可追溯报告。

S10. 可选地将高分辨率结果输入显示面板边缘检测、亮暗点检测、线宽测量或其他工业任务，并输出任务级技术效果。

## 六、拟保护的区别特征

以下特征应结合检索结果选择组合，不建议单独主张通用 IBP：

- 名义平台位移、图像估计位移和可选编码器位移的联合校正；
- 同时保留对齐位移与物理前向位移的统一符号体系；
- 由配准相关性、有效重叠和位移边界共同形成帧级置信度；
- 标定 PSF、像素积分和噪声模型共同参与前向投影及伴随反投影；
- 帧级置信度和像素级 Huber 影响函数的双层鲁棒约束；
- 伴随覆盖度归一化，抑制边缘欠覆盖区域的不稳定更新；
- 以重投影一致性作为无真值技术效果和停止依据；
- 扩展构想：根据配准失败或重投影误差自适应补采帧或调整后续位移轨迹，当前版本尚未实现；
- 面向特定工业检测任务的超分辨率成像与检测联动。

## 七、权利要求层级建议

独立方法权利要求可围绕“采集、实际位移估计、置信度生成、标定前向模型、鲁棒伴随反投影、重投影评价”形成闭环。

独立系统权利要求可包括采集模块、微位移模块、标定模块、配准模块、置信度模块、重建模块和检测/评价模块。

从属权利要求可分别限定：

- 2 x 2 或其他亚像素位移轨迹；
- 相位相关与 ECC 两级配准；
- 置信度阈值及异常帧处理；
- 圆盘、高斯或实测二维 PSF；
- 泊松-高斯噪声标定；
- Huber 截断参数；
- 覆盖度归一化；
- 早停与最佳迭代回退；
- 扩展实施方式：RAW/Bayer、多光谱或偏振通道，完成实测后再写入正式实施例；
- LED/OLED、晶圆、PCB 或精密尺寸检测应用。

还可准备电子设备和计算机可读存储介质权利要求，但其内容应与方法步骤对应。

## 八、当前实施例结果

软件版本：PixelShiftSR 2.0.0。

固定随机种子、128 x 128 通用测试图、四个半 LR 像素位移、2 倍重建、40 次迭代：

| 实施例 | SR PSNR | 双三次 PSNR | PSNR 增益 | 重投影 MSE 降幅 |
| --- | ---: | ---: | ---: | ---: |
| 无模糊无噪声 | 31.41 dB | 22.39 dB | 9.02 dB | 99.46% |
| 3 像素散焦和泊松-高斯噪声 | 26.54 dB | 21.94 dB | 4.60 dB | 93.54% |

标定实施例从候选模型中正确选择圆盘散焦核 kernel=3，拟合得到的噪声参数接近模拟设定值。自动配准实施例正确识别四帧，并输出置信度和实际位移。

上述结果只证明软件链路可行。正式申请前必须补充真实硬件实验、重复性统计、现有技术对比和应用任务效果。
